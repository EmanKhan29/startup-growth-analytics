# Startup Growth Analytics

A data analytics project analyzing customer acquisition, retention, and unit economics for a fictional B2B SaaS startup.

## Business Question

The company is growing, but management is unsure which acquisition channels are generating the most valuable customers.

The goal of this analysis is to determine how the company should allocate its next $100,000 of marketing spend.

## Analysis

This project will evaluate:

- Customer acquisition cost (CAC)
- Conversion rates
- Customer lifetime value (LTV)
- LTV / CAC
- Customer churn
- Cohort retention
- Acquisition channel performance
- Marketing spend efficiency

## Tools

- SQL
- Python
- Pandas
- Jupyter Notebook
- Matplotlib

## Project Structure

- `data/` - Customer and marketing datasets
- `sql/` - SQL queries used for analysis
- `notebooks/` - Python analysis
- `outputs/` - Charts and analysis outputs
